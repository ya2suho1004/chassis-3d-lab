## 0. 한눈에 보기

- **무엇**: 대구공고 섀시 실습장을 3D로 재현한 브라우저 게임. 학생은 아바타로 실습장을 돌아다니며 장비를 찾고, "작업지시서(퀘스트)"를 받아 제동장치 검사 과제를 수행하고, 계기를 읽어 기록표를 작성·판정한다.
- **누가·어디서**: 학급 20~25명이 태블릿·PC·폰 브라우저에서 동시에, 설치 없이. HMD 없음.
- **왜**: 실습 전 장비 위치·절차 사전 숙지, 대기 조 재연습, 판독 능력 연습. 수행 기록은 익명 코드로 구글 시트에 자동 전송되어 논문 데이터가 된다.
- **대상 단원(1차)**: 제동장치 점검·제동력 측정. 판독 과제 4종(제동력, 디스크 두께·런아웃, 페달 유격·작동거리, 주차브레이크 클릭수).

## 2. 요구사항

### 2-1. 기능 요구사항
1. **실습장 탐색**: 바닥을 탭하면 아바타가 걸어간다. 드래그로 카메라 회전, 두 손가락으로 확대·축소. 벽·장비는 통과하지 못한다.
2. **장비 위치 학습**: 장비를 탭하면 정보 카드(이름, 용도, 안전 수칙, 관련 과제)가 뜨고, 처음 탭한 장비는 **도감**에 등록된다(예: 7/12 수집).
3. **퀘스트 보드**: 작업지시서 목록. 과제별 Lv1(견습·안내 있음) → Lv2(정비사·안내 없음) → Lv3(검사관·시간제한·채점). 앞 레벨을 통과해야 다음이 열린다.
4. **퀘스트 수행**: 체크리스트 순서대로 장비로 이동·조작. Lv1은 화살표·하이라이트·설명, Lv2는 오류 시 즉시 설명, Lv3는 타이머와 짧은 경고만.
5. **안전 인터록**: 보호구 미착용, 리프트 승강 전 주변 미확인 같은 위반은 진행을 막고 붉은 경고를 띄운다. 위반 수를 기록한다.
6. **계기 판독**: 측정 단계에서 계기 화면(2D)이 뜬다. 학생이 눈금·숫자를 읽어 기록표에 입력한다. 값은 시나리오에 고정돼 있다.
7. **기록표·판정**: 기능사 답안지 형식(측정값 → 규정값 → 양호/불량 → 조치). 제동력은 편차·합 산출 근거 칸 포함. 판정은 `judge.js`로 자동 채점해 학생 판정과 비교한다.
8. **결과 화면**: 완료 시간, 오류 수·내용, 판독 정답 여부, 힌트 수, 안전 위반 수, 별점(시간·오류·안전 각 1개), 무재해 배지.
9. **교사 화면**: 규정값 입력, Apps Script URL 입력, Lv3 해금 기준·시간제한 설정, 기기에 쌓인 기록 CSV 다운로드, 전송 대기 수 확인. PIN으로 보호.
10. **조작 튜토리얼**: 첫 실행 시 1분 분량(이동·회전·장비 탭·체크리스트).

### 2-2. 비기능 요구사항
- 저사양: 단순 도형(저폴리곤), 그림자 없음, 화면 배율 1.5 제한, "저사양 모드" 토글. 크롬북에서 30fps 목표.
- 터치 우선, 가로 화면 권장(세로면 안내 문구). 버튼 최소 44px.
- 오프라인에서도 플레이 가능(정적 파일). 기록만 나중에 전송.
- 개인정보 없음. 익명 코드(`A-01` 형식) 외 식별 정보 입력란 없음.
- 확장성: 과제 추가 = `tasks.json` 과제 + 시나리오 JSON 1개 + 퀘스트 항목 1줄. 코드 수정 없음.

## 3. 기술 선택

| 역할 | 선택 | 한 줄 설명 |
|---|---|---|
| 화면 틀 | React 18 + Vite 5 | 교과서와 같은 스택. 빌드하면 정적 파일 |
| 3D | three.js + @react-three/fiber + @react-three/drei | 브라우저 3D 라이브러리와 React 연결 도구 |
| 상태 관리 | zustand | 화면 사이에서 "현재 퀘스트·기록"을 공유하는 작은 저장소 |
| 길찾기 | 자체 격자 A* | 바닥을 0.5m 격자로 나눠 벽을 피해 가는 길을 계산 |
| 저장 | localStorage | 브라우저 안 저장소. 설정·진행·전송 대기 기록 |
| 전송 | fetch → Google Apps Script | 구글 시트에 붙는 작은 서버. URL 하나로 기록 수신 |
| 테스트 | vitest | 판정·시나리오·별점·CSV 같은 계산 로직 자동 검사 |
| 배포 | GitHub Pages(비공개 저장소는 Actions로 빌드) 또는 단일 html | 정적 호스팅 |
| 3D 에셋 | 기본 도형 + 필요 시 CC0(Kenney 등) | 라이선스 불분명 모델 금지 |

### 4-2. 데이터 파일 (핵심 필드만)

**tasks.json** — 교과서 스키마 그대로(`id, title, objective, safety[], tools[], parts[], steps[], checkpoints[], recordSheet{rows[], judgment, compute}`). `video`는 쓰지 않지만 삭제하지 않는다. 수정 1건: `brake-pedal.travel`의 `standardType: "min"` → `"range"`.

**standards.json** — 키 `"{taskId}.{rowKey}"`. 초안값은 기능사 답안지 예시에서 가져오고 교사가 설정 화면에서 덮어쓴다(localStorage 병합).
```json

"brake-pedal.freeplay": { "type": "range", "min": 4,   "max": 10,  "unit": "mm", "draft": true },
"disc-thickness-runout.thickness": { "type": "min", "min": 20,  "unit": "mm", "draft": true },
"disc-thickness-runout.runout":    { "type": "max", "max": 0.1, "unit": "mm", "draft": true },
"parking-brake-clicks.clicks":     { "type": "range", "min": 6, "max": 8, "unit": "회", "draft": true,
                                     "note": "NCS 모듈은 5~7노치(20kgf). 교사 확인" }
```

## 5. 화면 흐름

```
[시작] 익명 코드 입력(A-01) · 아바타 색 선택
   ↓ (첫 실행만)
[튜토리얼] 탭 이동 → 드래그 회전 → 장비 탭 → 체크리스트 완료
   ↓
[실습장 3D] 자유 탐색 · 장비 탭 → 정보 카드 · 도감 등록
   │  HUD: [퀘스트 보드] [도감 n/12] [설정]
   ↓
[퀘스트 보드] 작업지시서 카드 × 레벨(잠금 표시) → "출동"
   ↓
[퀘스트 수행] 3D + 체크리스트 패널(Lv1 화살표·하이라이트 / Lv2 오류 설명 / Lv3 타이머)
   ├─ 안전 위반 → 붉은 경고, 진행 차단
   ├─ 측정 단계 → [계기 화면] 눈금 읽기 → [기록표] 입력·산출·판정·조치
   ↓
[결과] 기록표(기능사 양식) · 시간·오류·정답·힌트·안전 · 별점·배지 · 다음 레벨 해금 안내
   │  → 기록 저장 → 전송(실패 시 큐)
   ↓ 실습장으로 복귀

[교사 화면] 시작 화면 톱니 → PIN → 규정값 · Apps Script URL · 해금 기준(기본: Lv2 오류 ≤2) ·
            Lv3 시간(기본 300초) · CSV 내려받기 · 전송 대기 n건 재전송
```

레벨별 동작 차이:

| | Lv1 견습 | Lv2 정비사 | Lv3 검사관 |
|---|---|---|---|
| 안내 | 다음 장비 화살표·하이라이트·설명 팝업 | 없음 | 없음 |
| 오류 시 | 설명 + 올바른 단계로 되돌림 | 즉시 "왜 틀렸는지" 설명, 오류 1회 기록 | 짧은 경고, 오류 기록 |
| 힌트 | 무제한(횟수 기록) | 버튼, 횟수 기록 | 없음 |
| 시간 | 없음 | 없음 | 제한(교사 설정) |
| 해금 | 처음부터 | Lv1 완료 | Lv2 오류 ≤ 기준 |

## 6. 기록 전송 (쉬운 설명)

- **Apps Script란**: 구글 시트에 붙일 수 있는 작은 프로그램. 한 번 "웹 앱으로 배포"하면 주소(URL)가 생기고, 앱이 그 주소로 기록 1행을 보내면 시트에 자동으로 추가된다. 교사 구글 계정만 있으면 되고 서버 비용이 없다.
- **흐름**: 결과 화면 → 기록을 기기 저장소 큐에 넣음 → 즉시 전송 시도 → 성공하면 큐에서 지움, 실패(오프라인·주소 미설정)하면 그대로 두고 다음 실행·다음 결과 때 재시도.
- **CSV 예비**: 교사 화면에서 그 기기에 쌓인 모든 기록을 CSV 파일로 내려받는다. 시트 전송이 안 될 때 학생 기기에서 모아 받는 용도.
- **보안**: 보내는 내용은 익명 코드와 수행 기록뿐. 시트 주소는 교사 화면에서 입력하고 코드에 넣지 않는다.
- **교사 준비물(구현 후 안내)**: 구글 시트 새로 만들기 → 확장 프로그램 > Apps Script에 `apps-script/Code.gs` 붙여넣기 → 배포 → URL을 교사 화면에 입력.

## 8. 최소 동작 버전(MVP) 범위

"가장 작은 동작 버전"은 처음으로 학생이 끝까지 해볼 수 있는 1차 완성본이다.

**1차(MVP)에 포함**
- 시작(코드 입력) → 튜토리얼 → 실습장 탐색(임시 배치, 장비 8~12개) → 도감
- 퀘스트 1개: 제동력 측정 Lv1·Lv2·Lv3 (안전 인터록, 계기 판독, 기록표, 판정)
- 결과 화면, 별점·배지, 레벨 해금
- 기록 생성 → 큐 → Apps Script 전송 → CSV 내려받기
- 교사 화면 최소(Apps Script URL, PIN, CSV)

**2차**
- 나머지 3과제(디스크, 페달, 주차브레이크) 시나리오·계기 화면
- 교사 화면 전체(규정값 입력, 해금 기준, 시간제한)
- lab_site 자료로 실제 배치 교체, 저사양 모드, 사용성 검토 반영

**3차(연구 이후)**: 조향·현가 단원 과제 추가.
