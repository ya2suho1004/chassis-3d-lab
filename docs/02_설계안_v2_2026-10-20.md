## 2. v1에서 바꾸는 결정

| v1 | v2 (바꾼 이유) |
|---|---|
| 교과서 `judge.js`를 그대로 복사 | **이식하되 교정**: 규칙이 없으면 8/20/50을 자동으로 넣던 것 제거, 음수·공백·Infinity 차단, 앞/뒤 축 미지정 시 판정 불가. 교정 전후를 테스트로 남긴다 |
| 기록 저장은 localStorage | **IndexedDB**(브라우저 안의 더 큰 저장소). 수행 중 자동저장·새로고침 복원·전송 대기열을 트랜잭션으로 다루기 위해 |
| 기록 1건 = 단순 행 | **recordPayload(확정 내용, 불변) + deliveryEnvelope(저장·전송 상태)** 분리. 같은 recordId 재전송은 같은 접수번호, 내용이 다르면 충돌. 학생 최초 답과 최종 답을 둘 다 보존 |
| 제동력 Lv1 값 180/170/500(임의) | **26번 사진의 학교 고정 예시 ‘후 좌 240kg·우 200kg·후축중 600kg’**을 Lv1 사례로. 단위는 kg 그대로(kgf·N으로 바꾸지 않음). 판정 기준 8/20/50은 교사 승인 전까지 ‘미승인’ 표시 |
| 규정값 초안을 `draft:true`로 넣음 | 초안 숫자는 교사 확인지에만 두고, 앱 설정은 **승인 전 null**. 승인 전 수행은 `runPurpose=demo`, `researchEligible=false` |
| Lv3(검사관·시간제한)을 1차에 포함 | **데이터에는 유지, 1차에서는 비활성** (질문 1). 시간 공정성 정책이 정해지면 2차에서 켠다 |
| 단계 = 안내 → 무안내 → 평가 | 여기에 **수업 시점 축**을 더한다: 대기 중 예습 → 실제 실습 → 실습 후 복습. 예습/복습은 ‘언제’, 안내/무안내는 ‘어떻게’. 둘을 합친 모드 이름을 만들지 않는다 |
| 별점(시간·오류·안전 각 1개) | 유지하되 **합산 점수·100점 환산은 만들지 않는다**. 별은 학생용 표시이고 연구 지표는 원 기록(시간·오류 수·안전 위반 수) |
| 기록 전송: 앱 → Apps Script 직접 | 두 안 비교 중 (질문 2). 어느 쪽이든 ‘기기 저장 완료 → 전송 → 서버 접수번호 확인’ 세 상태를 따로 보여 준다 |
| 실습장 임시 배치(20×12m 가정) | **치수 가정 금지**. 사진·스케치의 상대 배치(장비 21묶음)만 쓰고, 실측 전까지 좌표·치수는 null. 북·동은 막힌 면, 남·서는 엔진·전기 구역과 트인 면, 섀시 구역 별도 입구 없음 |
| JavaScript | **TypeScript** 권장(인계 설계). 계약 필드가 많아 실수를 줄이기 위해. 비개발자에게 보이는 차이는 없음 |
