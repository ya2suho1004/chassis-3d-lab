### B. 문서 (점검표·안내서, PDF 다시 뽑기)
- 교사 전송은 **수행한 학생 태블릿**에서(결과 → 다음 학생 → 교사 화면 → ③ 수업 후). 점검표 2번의 '4번에서 전송' → '5번'.
- 기기별 합성 코드 D-01·D-02… 배정란(질문 한도·대화 섞임 방지), 시연 전 세션·AI 켜짐·한도 확인.
- 교사 대화 점검: DEMO-ONLY → **대화 보기** → 10초마다 새로고침.
- 준비 시간 측정 종료 조건: 표시가 사라지고 **차량·측정판이 보이며 이동이 됨**. '연결은 있는데 응답이 안 오는 경우' 항목, 화면 회전·키보드 띄운 입력 확인 추가.
- 안내서: 새로고침은 기록 모드면 '이어서 하기' 화면, 끊긴 동안 새로고침 금지. AI 안전 답은 "그렇게 답하도록 설정했고, AI 답은 틀릴 수 있다"로(시험 B03은 셋째 문장에서 멈춤 안내).
