# Codex 교차 검토 요청 — 11-10 시연·11-11 교수님 링크 전 품질 점검 (2026. 11. 6.)

> Claude Code(개발 담당)가 Codex에게 보내는 요청. MOON(이재문 선생님)이 "다른 AI의 눈으로 시연 상태를 점검하고 품질을 끌어올리자"고 해서 만든 문서다.
> 답을 받으면 Claude Code가 지적마다 코드에서 직접 확인한 뒤 반론하거나 받아들이고, 합의한 목록을 MOON에게 올린다.

## 0. 규칙 (꼭 지킬 것)
- **읽기만 한다.** 파일 수정·생성, git commit/push, 배포, 패키지 설치 금지.
- **네트워크 호출 금지.** 특히 AI 교관 챗봇 주소(`VITE_CHAT_ENDPOINT`)는 실제 Supabase 서버라 질문 하나도 보내지 않는다. 기록 전송(`submit`)도 마찬가지다.
- 개발 서버를 띄우지 않아도 된다. 코드·문서·첨부 그림으로 판단한다. 시험은 `npx vitest run` 정도만 괜찮다(오프라인).
- 추정과 확인을 나눠 적는다. 코드에서 본 것은 `파일:줄`을 붙이고, 보지 않은 것은 "추정"이라고 쓴다.
- 답은 **한국어**로, 비전공자 교사가 읽을 수 있게 쓴다(전문용어는 한 줄 풀이).

## 1. 배경
- 무엇: 섀시 가상 실습장(React + TypeScript + react-three-fiber). 특성화고 친환경자동차과 학생이 3D 정비소에서 교관 NPC에게 과제를 받아 **제동력 측정**과 **최소회전반경 측정**을 순서대로 수행하고 판정한다. AI 교관 챗봇은 질문에 답만 하고 판정은 하지 않는다.
- 왜: MOON의 석사논문(3D 게임 기반 시뮬레이션, 설계원리 → 프로토타입 → 사용성 평가 → 현장 적용). IRB 승인 전이라 지금 기록은 모두 가상·합성 자료다.
- 일정: **11-10 시연**(학교 태블릿 + 학교 Wi‑Fi), **11-11 지도교수님께 프로그램 링크 메일**(둘러보기 안내서 첨부).
- 공개 주소: `chassis-3d-lab.vercel.app` (production 브랜치 = `e0068c4`, 그 뒤 main은 문서만 추가).
