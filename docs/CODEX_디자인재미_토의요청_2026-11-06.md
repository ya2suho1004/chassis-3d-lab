# Codex 토의 요청 — 화면 분위기와 재미 요소 (2026. 11. 6.)

> Claude Code → Codex. MOON(이재문 선생님)이 "미적으로나 게임 운영 방식으로나 **마비노기 모바일**을 지향한다. 디자인을 어떻게 바꾸면 비슷한 느낌이 날지, 무엇보다 재미있어야 하니 재미 요소를 어떻게 넣을지 Codex와 토의해 달라"고 했다.
> 이번은 **아이디어 넓히기(발산) 단계**다. 결정·구현은 MOON이 고른 뒤. 11-10 시연 전에는 코드를 고치지 않는다(11-08 코드 고정).

## 0. 규칙
- 읽기만(파일 수정·설치·배포·네트워크 호출 금지). 답은 한국어, 비전공자 교사가 읽을 수 있게.
- **특정 게임을 베끼지 않는다.** 마비노기 모바일의 그림·캐릭터·로고·아이콘·UI 모양·음악·이름·세계관 용어를 가져오지 않는다. 그 게임이 주는 **느낌을 만드는 원리**(색·빛·형태·움직임·피드백·운영 방식)를 우리 실습장에 맞게 **새로 만드는** 방향만 낸다. 원리 설명은 일반 게임 디자인 용어로 하고, 확실하지 않은 그 게임의 세부 사실은 "추정"이라고 쓴다.
- 이미 정한 금지: 실제 얼굴·실존 인물 닮음 금지, 학교 공식 교표 금지, 마비노기 자산 금지.

- 게임식 화면(D17): 3D 꽉 찬 화면, 왼쪽 위 상태·메뉴, 오른쪽 위 퀘스트, 왼쪽 아래 조이스틱, 오른쪽 아래 행동 버튼, 작업 목록·AI 질문은 서랍. NPC 대화창(말풍선). 시점 3단계(내려다보기·따라가기·내 눈으로). 도감(장비를 눌러 채움, 0/23). 캐릭터 만들기(체형·머리·색·조합형 닉네임, 실습복 고정). 인트로(학과 로고 → 셔터 → 노란 차).
- 시작·결과·교사 화면은 흰 바탕 일반 웹 화면이다(게임 화면과 분위기가 다름).
- 연습 장면: 디스크 런아웃·차동기어 백래시(기록 없음).

## 2. 지켜야 할 조건
- **수업·연구 목적이 먼저**: 특성화고 학생이 제동력·최소회전반경 측정 순서와 판정을 익히는 4~6차시 단원. 사용성 평가 → 현장 적용(사전·사후 검사 11문항). 재미가 학습 목표를 가리면 안 된다(주의 분산, 겉도는 보상).
- **판정·채점·기록 형식은 그대로**(승인된 계산식·안전 조건·최초 응답 피드백 정책). 안내 없음 단계는 최초 응답 전 정답·해법·다음 단계를 자동으로 드러내지 않는다.
- **IRB**: 새로 모으는 자료가 생기면 IRB 서류를 고쳐야 한다. 재미 요소는 가능하면 기기 안에서만(기록·서버에 안 남김) — 남겨야 하면 그렇게 표시.
- **학교 태블릿**(저사양, 학교 Wi‑Fi, 처음 받는 자료 약 6 MB). 무거운 효과는 품질 높음 전용.
- 개발은 Claude Code가 하지만 시간은 한정(논문 집필 병행). 블렌더 스크립트 모델·CSS·SVG로 만들 수 있는 것 위주.

## 3. 묻고 싶은 것
- **Q1. 분위기를 만드는 원리**: 그 게임 같은 "아늑하고 따뜻한 생활형 판타지 RPG" 느낌은 무엇이 만드나? (색감·조명·형태 비율·외곽선·재질·UI 모양·글꼴·소리·움직임·카메라 등) 원리별로.
- **Q2. 우리 앱에 옮기면**: 원리마다 실습장에 맞는 구체 변경안(예: 3D 셰이딩, 정비소 조명·색, 캐릭터 비율, UI 패널 재질·모서리·아이콘, 시작·결과 화면을 게임 화면처럼, 대화창 초상화, 효과음·배경음). 각 안에 노력·태블릿 부담·위험.
- **Q3. 재미 요소**: 실습 학습과 맞물리는 재미(겉도는 점수판이 아니라). 예시는 참고만 하고 자유롭게: 정비사 등급·칭호, 도감 완성 보상, 실습복·장식 꾸미기, 교관과의 관계·대사, 하루 의뢰(손님 차량 사연), 안전 수칙 지키면 받는 무엇, 연습 장면 미니게임화, 동작 연출·손맛(타격감), 사진 찍기, 친구와 함께(같은 반) 등. 각 안에 **학습 목표와의 연결**, **연구·IRB 영향**(기록 필요 여부), **안내 없음 규칙과 충돌 여부**, 노력.
- **Q4. 위험·반대 의견**: 재미 요소가 연구 결과를 흐리거나(예: 보상 때문에 빨리 누르기), 학생을 산만하게 하거나, 수업 시간을 잡아먹을 가능성. 넣지 말아야 할 것.
- **Q5. 순서 제안**: 11-11 이후 4학기 전까지 할 만한 것을 작은 것(1일 이내)·중간(2~4일)·큰 것(1주 이상)으로.

## 4. 답 형식
- Q1~Q2는 원리 → 변경안 표: | 원리 | 지금 앱 | 바꾸는 안 | 노력 | 태블릿 부담 | 위험 |
- Q3은 표: | 재미 요소 | 어떻게 | 학습 연결 | 기록·IRB | 안내 없음 충돌 | 노력 |
