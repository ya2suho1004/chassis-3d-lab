> **결정(2026-11-16 MOON): 초안 표 그대로 반영.** 규정값·공식·절차 문장(★)은 모두 그대로 둠. 근거 꼬리표는 게임 화면 장비 카드에서만 없앰. 설계는 `docs/superpowers/specs/2026-11-16-equipment-info-copy-design.md`.
> 원칙: 지금 설명에서 **개발 메모만 떼어 낸다.** 규정값·공식·절차 문장은 임의로 더하거나 빼지 않았고(★ 표시), 남길지는 MOON이 정한다.

## 왜 고치나
- 배치 자료(`src/data/layout/layout.dev-provisional.json`)의 `equipment[].info`가 장비 카드와 도감 창에 그대로 나온다.
- 그 안에 "가로 2.20 실측, 세로·위치 가정", "(2026-10-29 사용자 지시, 남북 위치는 실측 아님)" 같은 개발 메모가 섞여 학생에게 보인다.
- 장비 카드에는 "[부분 실측]" 같은 근거 꼬리표도 보인다.

## 표 읽는 법
- **바뀜**: `그대로` = 손대지 않음 / `메모 뗌` = 개발 메모만 떼어 냄 / `새로 씀` = 지금 글이 전부 메모라 학생용 문장을 새로 썼음(MOON 확인 필요)
- **★**: 규정값·공식·절차가 든 문장. 아래 "MOON이 정할 것"의 번호와 이어진다.
- 떼어 낸 메모는 버리지 않고 같은 장비의 `note`(앱이 읽지 않는 기존 메모 칸)로 옮긴다.
