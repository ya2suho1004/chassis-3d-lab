11-10 시연 진행표

섀시 가상 실습장 · 공개 주소 chassis-3d-lab.vercel.app · 학교 태블릿 · 전체 약 15분(질의응답 별도)

시작 전 확인 — 시연 30분 전

  • 태블릿 충전 80% 이상, 충전기 가까이. 크롬에서 chassis-3d-lab.vercel.app이 학교 Wi‑Fi로 열린다.
  • 한 번 끝까지 열어 두기(시작 화면에서 30초쯤 두면 3D 자료를 미리 받음). 실습장 메뉴(☰)에 품질 낮음(태블릿)이 켜져 있다.
  • 소리: 태블릿 음량을 켜고, 무음 모드가 아님을 확인.
  • 교사 화면 ② 수업 중에서 DEMO-ONLY 세션 AI 켜짐 확인(교사 로그인은 직접). 교사 기기(노트북 등)를 따로 쓰면 그 화면에 대화 보기를 미리 열어 둔다.
  • 예비 영상 docs/demo/시연_예비영상_11-10.mp4(약 1분 50초, 11.7 MB)이 노트북·USB에 있고 인터넷 없이 재생된다.
  • 시연용 합성 코드(D-01 등)를 정해 두었다. 실제 학생 정보는 쓰지 않는다.

진행 순서

#장면 · 누를 것보여 줄 것 · 말할 거리시간
1인트로(로고·셔터) → 화면 누르기 → 시작 화면. 코드 D-01, 최소회전반경 측정 및 판정 — 사례 1, 안내 있음 → 과제 수령하러 가기 설치 없이 웹 주소로 열림, 학교 태블릿에서 동작.
학생 이름 대신 익명 코드만 씁니다. 과제·사례·안내 수준은 교사가 정합니다.
1분
2캐릭터 만들기(체형·머리·색·닉네임) → 이대로 시작 내 캐릭터로 실습장에 들어감.
캐릭터는 이 기기에만 저장되고 연구 자료로 쓰지 않습니다.
1분
3실습장 둘러보기: 왼쪽 조이스틱으로 걷기, 화면 끌어 둘러보기, 🎥 버튼으로 시점 바꾸기, 장비 눌러 설명 보기 오른쪽 위 도감 n/N이 채워짐.
실제 실습장 배치를 옮겼습니다. 과제 전에 장비 이름과 위치에 먼저 익숙해집니다.
2분
4교관에게 → 교관 누르기 → 과제 받기 → 시작하기 → 측정 차량에서 단계 수행, 📟 측정판 보기로 바퀴 각도 읽기 → 작업 목록에 입력 → NPC 검사 받기 안내 있음: 다음 할 일이 퀘스트 창에 나오고 해당 장비가 강조됨.
눈금을 직접 읽고, 공식으로 계산하고, 기준과 비교해 판정합니다.
4분
5(짧게) 시작 화면으로 돌아가 안내 없음으로 다시 들어가 과제를 받은 화면만 보여 주기 안내 없음: 다음 할 일·강조가 없고 “작업 순서는 목록에서 직접 고르세요(안내 없음).” 안전 경고는 그대로.
연구에서 비교할 두 조건입니다. 5차시 정리는 안내 없음으로 고정됩니다.
1분
6과제 중 💬 AI 교관에게 질문 → 미리 정한 질문 1개만 예: “측정판은 어떻게 읽어요?” / “최소회전반경은 무엇을 재는 거예요?”
교사는 ② 수업 중에서 질문과 답을 보고, 문제가 있으면 AI 지금 끄기로 바로 끕니다.
2분
7결과 화면: “수행 결과 — NPC 검사 통과”, 요약, 판독·계산·판정, 교사용 상세 기록 보기, 다음 학생 기록은 먼저 이 기기에 저장(“이 기기 저장됨”).
수업 뒤 교사가 ③ 수업 후에서 서버로 보냅니다. 와이파이가 끊겨도 수행 기록이 사라지지 않습니다.
2분
8(시간이 되면) 시작 화면 맨 아래 교사 화면(수업 설정·기록 관리) → ② 수업 중 대화 목록 / ③ 수업 후 전송 대기 교사가 수업 설정, AI 관리, 기록 전송을 한 곳에서 함.
③ 전송은 시연 기록이 서버에 남으므로 화면만 보여 줍니다.
2분

사고가 났을 때

상황이렇게
인터넷이 끊김, 주소가 안 열림바로 예비 영상(시연_예비영상_11-10.mp4)으로 넘어가 같은 순서로 설명. 이미 실습장 안이면 단계 수행은 계속 됨. 끊긴 동안 새로고침하지 않기.
3D가 느림·끊김메뉴(☰)에서 품질 낮음(태블릿) 켜기. “화면이 느려 … 품질을 낮췄습니다”가 저절로 뜨면 그대로 진행. 아래에 “3D 자료를 아직 받는 중… n%”가 보이면 둘러보기 설명으로 시간을 번다.
AI 답이 늦음40초 뒤 “답이 오래 오지 않았어요. 잠시 뒤 ‘보내기’를 다시 눌러 보세요.”가 나오면 다시 묻지 말고 다음 장면으로. 질문은 입력란에 남아 있음.
AI가 안 됨(“인터넷 연결을 확인한 뒤 다시 물어보세요.”, 꺼져 있음 안내)교사 화면에서 끄고 켜는 기능을 설명하는 것으로 대신하고 넘어감.
저장 실패·코드 문제결과에 “이 기기 저장 실패”가 나오거나 시작이 막히면 시작 화면에서 기록 없이 하기 → 이대로 시작으로 다시 시연(결과는 화면에만 보임).
태블릿 자체 문제노트북 크롬으로 같은 주소를 열거나 예비 영상으로.
