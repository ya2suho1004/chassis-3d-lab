## 검증 범위의 한계

- JSON Schema 검사는 실제 차량기준·안전절차·학교배치의 진위나 연구승인을 검사하지 않는다.
- 의미검증(세션스냅샷 실제대조, 응답항목 일치, 정오·유형별 합, 시간순서, 단위·출처·버전)은 향후 구현에서 필요하다.
- 앱·IndexedDB·접수 API·Google/Cloudflare 연결·학교기기·동시제출·JCS 종단간 실행은 아직 하지 않았다.
- Mermaid는 소스와 코드펜스·연결 명칭을 검토했으며 별도 렌더러 화면 검증은 하지 않았다.
- 문헌·NCS의 핵심 원문 페이지는 PDF 이미지로 별도 대조했으며, 신규 PDF 결과물은 만들지 않았다.
- 외부 계정·요금제·권한·배포 설정을 변경하지 않았고 Git push를 하지 않았다.
