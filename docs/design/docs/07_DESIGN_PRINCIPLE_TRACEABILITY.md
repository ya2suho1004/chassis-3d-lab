# 07. 설계원리와 게임 기능의 대응

상태: **설계 검토본 v0.1** · 검토일: 2026-10-16 · 앱 구현·실행 검증 전

이 문서는 선행문헌의 원리, 사용자의 결정, 본 설계의 적용 해석을 구분한다. 아래 대응표는 김민혁(2024)·한형종(2019)의 **학위논문 원문에서 직접 확인한 지침**을 사용했다. 문헌에 근거한 설계라고 해서 본 앱의 교육 효과나 실제 실습 대체 가능성이 입증된 것은 아니다.

범위는 [프로젝트 개요](00_PROJECT_BRIEF.md), 교사 운영 경로는 [기술 구조](03_TECH_ARCHITECTURE.md), 필드·이벤트·정오의 뜻은 [데이터 계약](04_TASK_AND_LOG_SCHEMA.md)을 따른다. 교사는 **비공개 Google Sheet의 설정 탭에서 검사 후 수업 공개**를 수행한다는 제안이며, 공개 학생 앱에는 설정 편집 화면을 만들지 않는다. 학생 앱은 `GET /api/sessions/{sessionCode}`의 승인된 세션 스냅샷만 읽는다.

## 1. 근거를 읽는 방법

- **원문 확인:** 확보된 학위논문 PDF의 최종 설계원리 표·본문을 직접 대조한 내용이다. 인쇄 쪽수와 PDF 면을 함께 적었다.
- **사용자 확정:** 1인 브라우저 실습, 학생 캐릭터와 NPC, 제동력 판독 단일 MVP, 안내/무안내, 기록 제출·접수 확인 등의 현재 요구다.
- **사용자 추가 확정(2026-10-16, 2026-10-20 갱신):** 실제 학교 실습장 배치를 최대한 재현한다. 2026-10-20에 사진 44장·손 스케치 1장을 확보해 상대 배치를 정리했고, 실측 치수는 아직 없다. 학교 배치로 확인되지 않은 좌표·치수를 만들어 확정하지 않는다.
- **적용 해석·제안:** 논문 지침을 PC·태블릿과 자동차섀시정비에 옮기는 본 설계의 판단이다. 최초 답 보존, 안전 경고 유지, 데이터 구조와 제출 방식 등은 논문의 검증 결과와 별개다.

`T01` 등은 대응표의 행 식별자이며 새로 개발·타당화한 설계원리 번호가 아니다. `K24 3.3`은 김민혁 논문의 지침3.3, `H19 7.3`은 한형종 논문의 지침7.3을 뜻한다.

PDF 면은 첫 파일 페이지부터 1로 센 값이다. 인쇄 쪽은 본문에 찍힌 숫자다. 위 대응은 이번 확보본에서 확인한 값이므로 다른 PDF에 고정 오프셋으로 적용하지 않는다. K24의 최종 원리는 8개·33지침이다(원문 p.149/PDF161). H19의 최종표에는 12개 원리가 있다. H19 분석 메모의 `표Ⅳ-53 p.294~315`는 표와 뒤의 해설 범위를 섞은 표현이며, 표 자체의 끝은 p.305이다.

**한형종·임철일(2020) 학술지 논문은 이번 직접 확인 출처가 아니다.** 연구계획서 참고문헌에 그 논문이 있더라도 2019 박사논문의 지침·쪽번호를 2020 학술지 출처로 바꾸어 쓰지 않는다.

## 5. 연구계획과 기록 해석

연구계획서 v3는 개발연구와 두 학급 준실험 비교, 사전·사후 장비·절차 숙지/측정값 판독 검사, 학습 태도 설문, 실험 학급 학생 5~6명의 면담을 계획한다. 교수학습 워크시트는 시뮬레이션을 **문제 확인 → 조사 → 시뮬레이션 → 실제 실습 → 평가 → 성찰 → 개선**의 일부로 배치한다. 실제 실습은 교사 임장 지도를 전제로 하며 가상 실습이 이를 완전히 대체한다고 계획하지 않았다.

## 6. 이번에 완료한 문헌 검증과 남은 일

완료한 일은 논문 표지·직접 인용 위치 확인, 최종표 텍스트 대조, **핵심 4쪽의 렌더링 이미지 시각 검증**이다. K24 p.140/PDF152·p.142/PDF154, H19 p.296/PDF311·p.305/PDF320에서 지침 번호·내용·하단 쪽수를 함께 확인했다. 원문을 길게 복제하지 않고 표의 내용을 요약하였다.

1. 실제 학교 실습장의 실측·상대 배치 초안 교사 확인·버전 확정(촬영·스케치는 2026-10-20 완료).

4. 위 표의 후속 기능 검증과 실제 학교 PC·태블릿·접근성·저장·전송 검증.
5. 실제 수업 적용 뒤 학습 결과와 경험 자료의 분석. **현재 교육 효과 결과는 없다.**
