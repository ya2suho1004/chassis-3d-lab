## 2. 범위 구분

- **구현 시작 가능(승인된 데이터 기준)**: 로드맵 1단계 — 3D 없이 제동력 과제의 단계 전이·안전 인터록·판정(교정된 judge 이식)·최초/최종 응답·요약·이벤트 계약. 승인 과제 JSON 2개(case-lv1, case-lv2)를 입력으로 쓴다. 1단계는 배치·좌표가 필요 없다.
- **시연 전용(runPurpose=demo)**: 3D 장면·배치는 `layout.surveyed.partial.json` + 상대 배치(v1-1)로 임시 구성. ‘실제 학교 재현 완료’라 부르지 않는다.
- **연구 적용 전까지 차단**: researchEligible=true 기록 생성, 실제 학생 데이터 전송, Sheet 운영 설정. 0C 시험과 연구자 승인 뒤에만.
