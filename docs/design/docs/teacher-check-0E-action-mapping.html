1. U1 — ‘판독(read)’ 단계에서 값이 고정되는 실제 조작 (장비 확인 필요)

NCS 원문은 “METER OFF → 롤러 정지 → 표시 고정 확인”인데, 14번 사진의 조작부(DKM-6000)에는 METER 버튼이 없고 ESC·SIDE SLIP·BRAKE·SPEED·AXLE Load·LIFT UpDn·MOTOR만 있습니다. 앱은 가짜 METER 버튼을 만들지 않았고, 지금은 좌·우 값을 입력하면 판독 단계가 끝납니다.

2. U2 — ‘정지·상승·이탈(off)’ 단계를 세 동작으로 나눔 (앱에 반영됨, 승인 요청)

앱 동작: ① MOTOR OFF(언제든 가능, 막지 않음) → ② 주변 확인(하강 때 확인을 다시 쓰지 않고 새로 확인) → ③ 리프트 상승(모터 켜진 채 누르면 ‘정지 확인 부족’ 안전 차단, 주변 확인 없이 누르면 ‘주변 확인’ 차단) → ④ 차량 빼기(상승 전에 누르면 안전 차단). 0A의 12단계 번호와 순서는 그대로이고, 기록에는 off 안의 하위 행동이 off:motorOff·off:liftUp·off:exitVehicle로 남습니다.

2-2. 상승 직전 ‘주변 확인’을 하강 때와 별도로 다시 요구

3. U3 — 점검 단계(타이어·설비) 전 ‘시동 OFF 확인’ (앱에 반영됨, 승인 요청)

0A의 안전 6조건 중 ‘측정 외 점검 시 시동 OFF’(s-engine)가 앱에 연결돼 있지 않았습니다. 이제 타이어 점검·설비 점검 전에 ‘시동 OFF 확인’ 버튼을 눌러야 하고, 안 누르면 안전 차단과 전용 안내 문구(아래 4의 blocked_safety_engine)가 나옵니다. 측정 중(모터 ON)에는 적용하지 않습니다.
