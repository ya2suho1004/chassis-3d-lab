# 비기록 모드 설계 (2026-11-02, 사용자 승인)

## 목적
- 연구에 참여하지 않는 학생이 같은 과제를 하되, 기기 저장·서버 전송·외부 AI 전송을 모두 끈 상태로 쓰게 한다.
- IRB 원고 2-2의 "로컬·서버 기록·AI 전송 차단 모드 [구현 확인]"을 학생 적용 전에 구현·시험으로 확인한다.
- 비교 학급의 연구 종료 후 이용, 수업 밖 복습에도 같은 기능을 쓴다.

## 결정(사용자 2026-11-02)
- **켜는 곳:** 시작 화면의 「기록 없이 하기」 버튼. 익명 코드는 입력하지 않는다.
  - 과제 사례·차시·도움 방식은 시작 화면 선택을 따르고, 교사가 잠근 설정도 그대로 따른다.
- **만드는 방식(A안):** 같은 `Repository` 인터페이스를 따르는 메모리 저장소(`openMemoryRepository`)를 비기록일 때 넘긴다.
  - 과제·판정·NPC 코드는 바꾸지 않는다.
  - 곳곳에 조건을 넣는 B안과 전용 화면을 따로 만드는 C안은 버린다(새는 곳이 생기기 쉬움, 화면이 중복됨).

## 동작
| 항목 | 일반 | 비기록 |
|---|---|---|
| 초안·확정 기록 | IndexedDB `chassis-3d-lab` | 메모리(탭을 닫거나 새로고침하면 사라짐) |
| 현재 수행 포인터(localStorage) | 씀 | 쓰지 않음 |
| 전송 대기 목록·교사 화면 기록 수 | 늘어남 | 늘지 않음(실제 저장소에 닿지 않음) |
| AI 교관 | 버튼·패널 | 숨김, 요청 0건, 대화 사본(IndexedDB `chassis-3d-lab-chat`)도 없음 |
| 과제·판정·NPC 대사·안전 경고 | 같음 | 같음 |
| 화면 표시 | — | 위쪽에 "기록 안 됨" 표시 |
| 결과 화면 | 기록 상태·payload·JSON/CSV 내려받기 | 판정·요약만 표시, "저장·전송되지 않았습니다", 내려받기 없음 |
| 이어서 하기 | 됨 | 없음(시작할 때 한 줄 안내) |

- 세션 값: 기존 시연 스냅샷을 그대로 쓰고, 익명 코드 자리에는 내부 표시값 `NR-00`을 넣는다. 이 값은 저장·전송되지 않는다.
- 화면 UI 설정(안내 창 봤음, 품질·소리 등 기존 localStorage 키)은 수행 기록이 아니므로 그대로 둔다.

## 구조
- `src/records/memoryRepository.ts`: `openMemoryRepository(): Repository`를 둔다.
  - 초안·확정 기록·포인터를 모두 메모리 Map에 둔다.
  - 확정 규칙은 같다(같은 ID 재확정 → ALREADY_FROZEN).
- `App.tsx`:
  - `lab`/`result` 화면 상태에 `noRecord: boolean`을 더한다.
  - 비기록이면 메모리 저장소를 만들어 LabScreen에 넘긴다.
  - '다음 학생'이면 시작 화면으로 돌아간다(실제 저장소 포인터는 건드리지 않음).
- `StartScreen`: 「기록 없이 하기」 버튼과 안내 한 줄을 둔다. `onStart`에 `noRecord`를 넘긴다.
- `LabScreen`: `noRecord`면 AI 교관 버튼·패널을 렌더링하지 않고, "기록 안 됨" 표시를 둔다.
- `ResultScreen`: `noRecord`면 저장·접수 상태, payload, 내려받기 칸을 숨기고 안내문을 보인다.

## 시험
- 메모리 저장소 단위 시험: 초안 저장·읽기·확정·ALREADY_FROZEN·outbox, localStorage 미사용.
- 비기록 흐름 시험(fake-indexeddb):
  - 메모리 저장소로 두 과제(제동력·최소회전반경)를 확정까지 수행한다.
  - 실제 DB `chassis-3d-lab`의 기록·초안 0건, 현재 포인터 없음, 대화 DB 없음을 확인한다.
- 기존 시험 전부 통과(일반 모드 회귀 없음).
- 개발 서버에서 비기록으로 한 과제를 끝까지 수행하고 아래를 확인·캡처한다.
  - IndexedDB 기록 0건, AI 요청 0건(네트워크 목록), "기록 안 됨" 표시, 결과 화면 안내

## IRB 인계
- 끝나면 Hermes에게 알린다. 원고 2-2·설명문 1절의 "[구현 확인]"을 "구현·시험 완료(2026-11-0x, 근거 커밋)"로 바꾸게 한다.
