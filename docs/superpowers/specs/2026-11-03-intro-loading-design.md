# 인트로(로고·셔터)·로딩 화면 설계 (2026-11-03, 사용자 승인)

## 목적
- 게임처럼 앱을 켜면 학교·학과 로고 → 셔터가 열리는 타이틀 → (코드·캐릭터) → 로딩 화면 순서로 이어지게 한다.
- 참고: 학과 홍보 영상 오프닝(4~10초) — 청회색 철판 롤셔터가 올라가며 어둠 속 노란 차의 헤드라이트가 번쩍인다.
- 영상·사진은 앱에 넣지 않고 분위기만 그림으로 다시 그린다. 마비노기 화면은 참고만 하고 그림·로고는 쓰지 않는다.

## 결정(사용자 2026-11-03)
- **로고:** 학교·학과 이름("대구공업고등학교 · 친환경자동차과")을 톱니바퀴·렌치 무늬와 함께 직접 그린다. 학교 공식 교표는 쓰지 않는다.
- **셔터 장면:** 그림 애니메이션(A안: SVG + CSS)으로 만든다. 3D 장면(B)이나 영상 삽입(C)은 하지 않는다.
- **차:** 머스탱 느낌의 노란 쿠페로 그리되 회사 엠블럼과 차 이름은 넣지 않는다.

## 흐름
1. **로고**(약 1.6초, 자동): 같은 기기에서 두 번째부터는 생략한다.
2. **타이틀:** 밤, 닫힌 청회색 셔터와 위쪽 학과 간판, "화면을 눌러 시작"이 깜빡인다. 누르는 동작이 브라우저 소리 허락 조건이 된다.
3. **셔터 열림**(약 3초):
   - 셔터가 올라가고(합성 셔터 소리) 노란 차 헤드라이트가 번쩍인다(합성 엔진 소리).
   - 이어서 하얗게 밝아지며 원래 첫 화면(시작 또는 이어 하기)으로 넘어간다.
4. **로딩 화면:** 실습장에 들어갈 때 3D 모델을 다 받을 때까지 보인다.
   - 열린 셔터 그림을 흐리게 깔고, 진행 막대(실제 %)와 팁을 3초마다 바꿔 보인다.
   - 기존 `g-loading`을 바꾼다.
- **미리 받기:** 인트로가 시작되면 모든 glb를 `useGLTF.preload`로 미리 받는다. 실습장에 들어갈 때는 캐시를 써서 로딩이 짧다.
- **건너뛰기:**
  - 화면을 누르면 다음 단계로 간다.
  - 움직임 줄이기(prefers-reduced-motion)가 켜진 기기는 인트로를 생략한다.
  - 교사 화면에 "시작 영상 끄기(이 기기)"를 둔다.
- **팁과 안내 없음 모드:**
  - 안내 없음(무안내)에서는 작업 순서를 알려 주는 팁을 보이지 않는다. 일반 안전·사용 팁만 보인다(다음 단계 비공개 원칙).
  - 비기록 모드에서는 AI 교관 팁을 빼낸다.
- **저장:** localStorage `chassis.intro.v1` = `{ seen, off }`. 화면 설정일 뿐이고 연구 기록과 무관하다.

## 구조
- `src/app/intro.ts`(순수)
  - `introPlan(prefs, reducedMotion)` → `'none'|'short'|'full'`
  - prefs 읽기·쓰기
  - `PRELOAD_MODELS`
  - `tipsFor({ guided, aiAvailable })`
- `src/app/introSound.ts`: Web Audio로 셔터 소리·엔진 소리를 합성한다. 실패해도 조용히 넘어간다.
- `src/screens/IntroArt.tsx`
  - 셔터·간판·벽·노란 차·헤드라이트 빛을 SVG로 그린다(`phase`: closed|opening|open).
  - 로고 그림도 둔다.
- `src/screens/IntroScreen.tsx`: 단계 진행, 누르기, 미리 받기, 끝나면 `onDone`.
- `App.tsx`: `introDone` 상태를 둔다. 저장소 열기는 뒤에서 계속한다.
- `LabScreen`: 로딩 화면을 바꾼다(그림·팁).
- `TeacherPanel`: 시작 영상 끄기 체크를 둔다.

## 시험
- `introPlan`: 끔·움직임 줄이기 → none, 처음 → full, 본 적 있음 → short.
- prefs 저장값 검사(깨진 값 무시).
- 미리 받기 목록이 `public/assets/models/*.glb`를 모두 포함한다.
- 팁: 무안내 목록에 작업 순서·장비 조작 낱말이 없다. AI 없음이면 AI 팁이 없다.
- 개발 서버(태블릿·폰): 로고 → 타이틀 → 열림 → 시작 화면, 두 번째 실행에서 로고 생략, 교사 끄기, 로딩 화면 팁을 확인하고 캡처한다.
