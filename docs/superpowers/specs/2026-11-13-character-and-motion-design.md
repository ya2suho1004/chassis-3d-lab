# 캐릭터와 움직임 다듬기 — 설계 (화면 품질 묶음 나)

- 날짜: 2026-11-13. 상태: 설계 승인(MOON, 2026-11-13), 1단계(모델) 진행 중.
- 앞선 묶음: 가(빛과 재질, `2026-11-11-light-and-material-design.md`), 다(손맛, `2026-11-12-feel-design.md`). 순서는 가 → 다 → 나 → 라.
- 진행 방식: 설계·검토·최종 확인은 지휘 세션, 모델 제작·구현은 Opus 워커, 확인 실행은 Sonnet 워커(작업 폴더 `CLAUDE.md`의 2026-11-13 규칙).

## 1. 목표
캐릭터가 마네킹처럼 보이는 인상(작은 머리, 가는 팔다리, 점 두 개 얼굴, 디테일 없는 옷)과 뚝 끊기는 움직임(가속·감속 없음, 격자대로 꺾이는 경로)을 없앤다.

## 2. MOON 결정 (2026-11-13)
1. 손볼 곳은 움직임의 질과 캐릭터 겉모습이다. 교관의 생동감(시선·고개)과 새 조작 몸짓은 이번에 하지 않는다.
2. 이동은 걷기만 두고 최고 속도 1.6 m/s를 유지한다. 달리기·빠른 걸음은 넣지 않는다(실습장 안전 수칙, 소요 시간 자료).
3. 겉모습은 시안 B(머리가 큰 3등신 안팎의 양식화 비례)로 새로 만든다. 시안 그림은 세션 임시 폴더의 `char-sian/`(compare·b-close·scale-front)에 있었다.
4. 학생 키는 1.45 m, 교관은 그보다 10~15% 큰 약 1.62 m로 한다.
5. 따로 답이 없어 추천대로 둔 것(바꾸기 쉬움): 1인칭 눈높이 1.6 m 유지, 교관은 어른 비례(3.4등신쯤)의 전용 모델 파일, 체형 2는 지금처럼 체형 1을 같은 비율(1.62/1.72)로 줄이고 어깨를 좁힌 것.

## 3. 범위
### 들어가는 것
1. 새 캐릭터 모델 3개: 학생 체형 1(1.45 m), 학생 체형 2(약 1.37 m), 교관(약 1.62 m). 실습복 깃·지퍼·주머니·반사띠, 작업화, 눈썹과 입이 있는 얼굴.
2. 캐릭터 만들기는 그대로: 체형 2종, 머리 4종, 머리색·피부색·눈 색, 보안경, 옷 색 체계. 화면과 저장값(`chassis.avatar.v1`)이 바뀌지 않는다.
3. 동작 6개(Idle·Walk·Gesture·Crouch·Press·Equip)를 새 비례에 다시 맞춘다. 가짓수와 길이(초)는 그대로다.
4. 이동 다듬기: 출발·멈춤의 가속·감속, 걷기 동작 속도를 실제 속도에 비례, 바닥 누르기 경로의 꺾임 다듬기.
5. 사람 키를 전제로 한 값 조정: 따라가기 카메라 목표 높이, 교관 대화 카메라, 캐릭터 만들기 미리보기 카메라, 교관 이름표 높이, 발밑 그림자 크기, 불러오는 중의 대체 모형, 촬영 도구의 카메라.

### 빼는 것
달리기, 교관의 시선·고개 돌림, 새로운 조작 몸짓, 다른 인물, 걷는 동안의 React 상태 갱신 구조 변경, 채점·기록 변경.

## 4. 지키는 것
- 최고 속도 1.6 m/s. 몸짓은 지금처럼 단계를 마친 뒤에만 나온다(안내 없음 원칙). 두 도움 방식에 똑같이 적용된다.
- 앱이 문자열로 기대하는 이름을 유지한다: 뼈 15개(Hips·Spine·Chest·Neck·Head, 팔·다리 좌우 3개씩), 동작 6개, 재질 Top·Trim·Bottom·Shoes·Skin·Hair·Eye·Goggles, 부품 Hair_Short·Hair_Fringe·Hair_Bob·Hair_Tied·Goggles, 뿌리 Character.
- 태블릿(늘 품질 낮음) 기준: 캐릭터 하나의 삼각형 수는 지금 수준(약 1만 개) 안, 모델 파일은 40만 바이트 미만(`tests/characterAsset.test.ts`), 품질 낮음의 그리기 호출 수는 지금 값 +2 이내, 높음은 +8% 이내. 재질을 늘려야 하면 캐릭터당 1개까지.
- 실제 인물의 얼굴이나 특정 게임·작품의 캐릭터를 따라 만들지 않는다. 상표·학교 표식을 넣지 않는다. 외부 자산을 내려받지 않고 Blender 스크립트로 자체 제작한다.
- 캐릭터 선택은 연구 기록·서버·AI 요청에 남지 않는다(지금과 같음). IRB 원고는 바뀌지 않는다.
- 겉모습이 바뀌므로 앱 판을 0.3.5-demo로 올린다.

## 5. 모델
- 생성 스크립트 `scripts/blender/build_character.py`는 관절 높이와 머리·옷 경계가 1.72 m 기준의 고정 숫자다. 치수 표 하나에서 모든 좌표를 계산하도록 다시 쓰고, 변형(학생 체형 1·2, 교관)을 인자로 고른다.
- 파일: `character.glb`(학생 체형 1), `character-b.glb`(학생 체형 2, 뿌리 scale 1.62/1.72 유지), `character-npc.glb`(교관, 새 파일).
- 동작은 지금처럼 뼈 회전 키프레임과 Hips 위치 키로 만든다. 길이는 지금 프레임 수를 유지한다(Walk 24, Idle 72, Gesture 48, Crouch 57, Press 34, Equip 38, 24fps) — 앱의 `ACTION_SECONDS`가 그대로 맞는다.
- 걷기 한 주기에 나아가는 거리(`WALK_CYCLE_DISTANCE`, 지금 1.47 m)는 새 모델에서 발이 미끄러지지 않는 값으로 다시 재서 앱에 넣는다. 발소리 보폭(`STEP_STRIDE`)은 그 절반이다.

## 6. 이동
- 현재 속도 값을 따로 두고 목표 속도로 0.2~0.25초에 걸쳐 따라가게 한다(조이스틱, 경로 이동 모두). 경로 이동은 도착 직전에 줄인다. 계산은 순수 함수로 떼어 시험한다.
- 걷기·서기 판정과 걷기 동작 재생 속도를 현재 속도에 맞춘다. 모션 줄이기 설정에서는 지금처럼 즉시 바뀐다.
- 경로 다듬기: A* 결과의 중간 점 가운데 막힘 없이 곧게 갈 수 있는 점을 건너뛴다(격자 판정 재사용, 순수 함수).
- 길 찾기 여유(0.3 m), 장비·교관 근처 판정 거리, 조준 거리는 그대로 둔다.

## 7. 확인
- 시험: 모델 파일(뼈·동작·재질·부품·크기·뿌리 scale), 가속·감속과 경로 다듬기 계산, 카메라 값.
- 화면: 촬영 도구로 바꾸기 전·후를 두 품질에서 비교(`cams`), `walk`·`ctx`·`toggle`·`goal`, 캐릭터 만들기 화면, 몸짓 6개.
- 중간 확인: 모델을 앱에 넣기 전에 완성 렌더(학생 두 체형, 교관, 머리 4종, 보안경, 동작 자세)를 MOON이 본다.
- MOON이 직접: 학교 태블릿에서의 화면 인상과 걷는 느낌.

## 8. 단계
1. 모델 제작(스크립트 다시 쓰기, 세 파일과 검토용 렌더) → MOON 확인.
2. 앱에 넣기(파일 교체, 교관 파일 연결, 키 전제 값 조정, 자산 꼬리표·문서 갱신).
3. 이동 다듬기(가속·감속, 걷기 동작 속도, 경로 다듬기).
4. 전체 확인, 앱 판 0.3.5-demo, 최종 검토.
2~3단계의 계획은 1단계 모델의 실제 치수가 나온 뒤에 세운다.
